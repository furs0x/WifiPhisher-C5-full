ESP32 固件刷写

1. 选择固件

填一个 ESP Web Tools 标准的 manifest.json 地址；芯片会自动识别并选择对应 build。

尚未选择 manifest。

2. 连接并刷写

需要桌面版 Chrome / Edge（≥89），并通过 https:// 或 localhost 访问。

说明：刷写由官方 <esp-web-install-button> 组件完成， 芯片识别、擦除、写入、进度和串口重连都由它处理。本页只负责加载组件和传入 manifest。

manifest 格式

官方标准：builds[]，每项含 chipFamily 与 parts[]；offset 用十进制。

展开示例 
{
  "name": "ESP32WifiPhisher",
  "version": "1.0.0",
  "builds": [
    {
      "chipFamily": "ESP32-S3",
      "parts": [
        { "path": "bootloader.bin", "offset": 0 },
        { "path": "partitions.bin", "offset": 32768 },
        { "path": "firmware.bin", "offset": 65536 }
      ]
    },
    {
      "chipFamily": "ESP32",
      "parts": [
        { "path": "esp32-bootloader.bin", "offset": 4096 },
        { "path": "esp32-partitions.bin", "offset": 32768 },
        { "path": "esp32-firmware.bin", "offset": 65536 }
      ]
    }
  ]
}
ESP Web Tools 10.x · 需 Chrome/Edge · 本页不收集任何数据
